# UI 验收测试账号

本仓库的本地 UI 验收账号保存在同目录的 [`ui-acceptance-test-accounts.local.md`](ui-acceptance-test-accounts.local.md)。该文件包含密码，已加入 `.gitignore`，只保留在本机，不得提交。

## 账号用途

| 用途 | 用户名 | 授权场景 |
|---|---|---|
| 超级管理员 | `ui_acceptance_super_20261002` | `admin` 角色、全部组织、授权总览和完整管理导航 |
| 受限审计员 | `ui_acceptance_auditor_20261002` | 本组织、授权总览／风险清单／角色详情／用户详情读取 |
| 风险只读用户 | `ui_acceptance_risk_20261002` | 本组织、仅风险清单读取 |
| 无管理入口用户 | `ui_acceptance_empty_20261002` | 无角色、空管理入口和个人资料流程 |

## 数据边界

- 测试组织编码：`ui_acceptance_org_20261002`
- 故意保留的风险角色编码：`ui_acceptance_risky_role_20261002`
- 账号由本地 MySQL 直接创建，后续测试继续复用。
- 未经用户明确要求，不删除账号、角色、组织或关联数据。

## 使用规则

1. 先读取本机的 `.local.md` 获取密码。
2. 使用真实验证码登录；验证码不写入文档、日志或验收证据。
3. 验收完成后停止本地服务即可，不执行数据库清理。
4. 生产环境、共享截图、提交记录和公开文档不得包含这些密码。
