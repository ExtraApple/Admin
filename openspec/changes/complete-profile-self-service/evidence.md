## 真实 HTTP 与后端观察

- `GET /api/user/avatar-upload-policy` 在两种真实部署上限下返回正整数 `data.max_bytes`，分别观察到 `1048576` 和 `3145728`，响应带 `Cache-Control: no-store`。
- 有效 Access 可读取规则；未认证和仅 Cookie 请求均被拒绝。普通有效用户可以读取规则，不需要新增权限码；手动权限同步前后该路由的策略权限数量均为 0。
- 真实 HTTP 验证了昵称保存后重读、JPEG／PNG／WebP 上传、服务端标准化读取、大小边界、内容安全失败和恢复默认；纯资料修改未改变授权版本或使头像失效。
- 真实注册和改密验证了多字节 UTF-8 72／73 字节边界、旧密码错误、确认值不一致、成功提交和授权版本提升。超限值在 bcrypt 前返回 422 字段错误；未签发新凭据，旧 Access／Refresh 后续失效。
- 通过真实 SQL 读取故障夹具分别制造提交前和提交后用户读取故障：前者返回安全 500；后者保持已提交昵称／版本并返回显示未确认语义；写响应丢失场景未自动重发写请求。

## 真实浏览器观察

- 三个独立 Chromium 标签验证了资料页重入、刷新后的最新显示和最后写入胜出；旧标签未收到伪造的资料广播。
- 真实文件选择只产生本地预览，取消不写服务端；显式上传成功后个人页和顶栏头像均读取服务端标准化图片。默认头像确认、取消和失败路径均保持草稿边界。
- 真实规则读取失败只禁用选图／上传；昵称、密码和恢复默认仍可用。取消导航确认保留输入，真正离开清除敏感草稿。
- 在有效 Access 下断开真实 Redis，观察到临时续期失败时密码草稿保留；签名 Access 实际到期后进入“需要恢复会话”，三项密码均清空，昵称和待保存头像预览保留。同 SID 手动恢复成功，未产生业务写请求重放。
- 三标签扣留旧头像读取和旧改密响应后切换到新身份；旧响应未触发新身份 Logout、未覆盖新身份头像或资料，旧文件和密码草稿已清除。
- 真实改密响应返回 200 后，故意停止隔离 Redis，使 Cookie Logout 返回真实 500。页面分开显示“密码已修改”和“退出尚未确认”；刷新后待确认标记仍在，未自动 Refresh、登录或重交密码。Redis 恢复并刷新实际映射端口、重启仅验收后端连接后，点击“重试退出”返回 200 并进入登录页，密码写入次数保持 1。另一轮故障验证了“重新登录”：显式登录完成真实 context 后清除待确认标记。
- 亮色／暗色、窄屏无横向溢出、键盘进入编辑区和可见焦点、减少动态效果均在真实页面观察；退出未新增二次确认。
