## Why

C5 审计确认到期公告发布、过期和临时消息图片清理只有应用服务实现，没有生产调度入口；未绑定图片因此持续占用存储。现有公告批量事务和“先删记录、再删对象”的路径也不能直接安全接线，需要在启用存量处理前统一限额、并发和可恢复清理契约。

## What Changes

- 接入现有 `messaging-cleanup`：启动立即执行，完成一轮后等待一小时，同进程不重叠；保留原有快照和终态 Consumer 死信清理。
- 新增唯一批量配置 `messaging.cleanup_batch_size`，默认 100，0 取默认，允许 1–1000。图片清理、公告发布、公告过期分别限额；15 分钟总边界内各 C5 子任务至多 5 分钟。
- 公告按组织副本独立事务和 CAS 转换，沿用现有消息事件与 Outbox；单条失败隔离，不新增发布状态或投递控制面。
- 启动时未配置 RabbitMQ 则跳过自动发布并记录原因，图片清理和过期仍执行；已配置但暂时断连仍提交事件，由既有 Outbox 有限重试和 dead 重放处理。
- Files 新增持久化消息图片清理队列：先登记，后删除对象，成功后条件删除 File Record 与队列；pending/dead 队列阻断读取、绑定及不安全轮转。
- 对象路径完整保留，以 SHA-256 路径键去重；删除失败每小时重试，最多 24 次，成功物理删除队列，dead 保留人工处理。
- 明确轮转交错、跨桶对象归属、历史配置路径、队列并发计数和有限批量公平性，不以扫描两个 bucket 代替一致性保证。
- 对已错过有效期的 scheduled 公告直接过期，不补发发布事件；跨轮内存游标防止固定坏记录长期占满批次。
- 未绑定消息图片不再参与轮转；绑定与清理登记采用仅覆盖数据库操作的短事务行锁。跨桶删除以应用独占命名空间和非版本化存储为部署前提，旧轮转请求必须在切换前排空。
- 新增受控轮次汇总和单条失败日志，沿用现有日志适配和白名单，不输出对象路径或原始内部错误，不新增对外 HTTP 错误码。

### 非目标

不新增 HTTP 路由、权限码、前端、dry-run、人工触发命令、C5 开关、公告失败表、分布式锁、清理租约或 processing 状态；不修改既有 Outbox 重试／dead 恢复机制；不删除有意保留接缝。数据库普通事务一致性不因这些限制而省略。

## Capabilities

### New Capabilities

无新增规格目录；能力分别归属现有消息、文件和日志规格。

### Modified Capabilities

- `internal-messaging`：新增周期维护与限额契约、公告副本级到期转换、RabbitMQ 门控及状态／事件一致性。
- `file-management`：细化临时图片清理和轮转边界，新增清理队列、重试终态、读取与绑定保护及受信对象删除范围。
- `logging`：新增 C5 调度结果、稳定运行码及敏感对象信息隔离要求。

## Impact

- 来源：`docs/reviews/c5-design-discussion.md`。正式细节与对讨论未决点的裁决由本 change 的 design 和 delta specs 承载；讨论记录不代表运行时事实。
- 生产代码范围：`internal/app` 的调度、迁移和日志适配；`internal/platform/config`、对象存储适配；`internal/messaging/application` 与 GORM 仓储；`internal/files` 模型、应用服务、仓储和对象存储边界。
- 数据库：新增 Files 所有的消息图片清理队列表和唯一索引，不删除历史数据、不在迁移期间执行对象清理；复用既有 AutoMigrate。File Record 不增加清理状态字段。
- 同步限定现有普通文件策略降级迁移只作用于 managed_file／兼容旧空用途，防止新增队列迁移触发启动时把合法消息图片改为 legacy_unverified；不自动升级已有未知状态。
- 对象存储：使用数据库登记的原始定位及可证明同归属的配置轮转位置；不创建新 bucket，不扫描任意历史 bucket。对象删除不可逆，上线前需核对存量与部署顺序。
- API、Redis key、权限码、消息事件名及对外响应结构不变；读取/绑定已登记清理的图片仍通过既有受控错误拒绝。
- 不新增第三方依赖或调度框架。配置启动读取、变更需重启；首次启动会处理到期存量，因此这是行为变更，不是纯重构。
- 实施时同步 `docs/runbooks/messaging.md`、`docs/runbooks/runtime-logging.md` 及审计索引；用针对性并发回归、独立 MySQL／MinIO 门禁和任务运行证据验收，不以工件完整代替实施完成。
