在前端正式 `/login` 路由观察到：

- 无保存偏好时实际使用跟随系统；保存亮色后刷新仍为亮色。
- 菜单有“亮色”“暗色”“跟随系统”三个选项，跟随系统在系统暗色时仍标记为跟随系统。
- 键盘打开菜单、单选和 Escape 关闭后，入口焦点恢复。
- 375px 窄屏入口仍可操作，按钮文字按窄屏策略隐藏但保留可访问名称。
- 两个同源登录页标签之间的模式和实际外观即时同步；接收标签不回写 storage。
- 被动主题更新保留登录表单输入、当前焦点和路由；清空主题偏好后恢复 system。
- 主题事件未产生业务 API 请求；页面控制台无错误。
- 登录后退出回到公开登录页时，主题枚举仍保留；登录页与注册页入口使用同一主题快照。
- 在浏览器媒体查询模拟亮色／暗色下，system 模式保持所选模式为 system 并即时切换实际外观；清除主题键后重新打开页面默认回到 system。
在最终隔离环境中，第一标签使用真实验证码登录并进入授权总览、角色列表、用户列表、组织列表、个人资料和角色权限编辑页；第二同源标签保持公开登录页并通过主题菜单触发 storage 同步。

角色权限编辑页中保留了一个未保存复选选择和打开的“放弃未保存的修改？”业务确认框。第二标签切换主题后，编辑页仍保持 `/roles/2/permissions`、选择状态、打开的确认框和焦点，且本次被动主题更新没有产生 API 请求。

桌面和 375px 窄屏下分别观察组织管理页的亮色与暗色；两种主题的 `document.scrollWidth` 均等于视口宽度。暗色正文／表面、亮色正文／表面、次级文字和强调色的实测对比度均达到规格阈值：

- 暗色正文与背景：`14.77:1`；正文与表面：`12.55:1`；次级文字与表面：`8.10:1`。
- 亮色正文与背景：`11.42:1`；正文与表面：`12.21:1`；次级文字与表面：`4.69:1`。

Portal 主题菜单、键盘 Escape、编辑状态、焦点、业务确认框和真实路由均已实际观察。
