## Why

现有管理工作台缺少桌面端已打开页面栏，在多模块间来回核对授权、用户、组织与审计记录时必须反复通过侧边栏跳转；同时侧边栏首次进入默认折叠其他分组、子路由面包屑缺失层级定位，页面内部也存在大号衬线页头、大边距、强制超高表格行（`88px–100px`）、路由切换焦点青框以及状态徽章折行等可读性问题。本次改造同步升级工作台壳层导航与桌面端排版信息密度，在不改变后端接口与业务契约的前提下，让高频后台操作更清晰、直观、可连续切换。

## What Changes

- **桌面端已打开页面栏（纯路由快捷页签）**：
  - 在桌面端（`>850px`）顶栏下层新增一行独立的已打开页面栏，采用双层吸顶顶栏（上层工具栏 + 下层页签栏）；窄屏（`≤850px`）隐藏该栏并继续使用移动抽屉 Sheet 与面包屑导航。
  - 按一级模块去重（最多 9 个模块：授权总览、风险清单、角色管理、用户管理、组织管理、菜单管理、接口管理、审计日志、个人资料）；进入模块详情/编辑子页或调整筛选分页时复用该模块页签并记住最近停留的完整 URL（含查询参数）。
  - 明确分工：点击顶栏已打开页签返回该模块上次停留的完整 URL；点击左侧边栏菜单返回该模块根入口路径。`/profile` 纳入页签栏；`/no-management` 仅在作为唯一可见页时展示；404（`*`）不写入页签列表。
  - 页签及其固定状态仅保留在当前工作台挂载周期的内存中，不写入 `localStorage`、`sessionStorage` 或服务端；登出或切换账号随会话重置自动清空；授权上下文更新导致模块失权时自动移除对应页签（含已固定页签）。
  - 不设默认强制钉住的首页签，仅剩最后 1 个页签时不可关闭（隐藏关闭按钮、禁用中键与对应批量项）；支持用户按需在当前会话内手动固定／取消固定业务页签（固定后自动归组至左侧已固定区、标题左侧显示图钉图标并隐藏 `×`，免疫单关、鼠标中键与批量关闭）；关闭当前页签优先切到右侧相邻页签（无右侧则切到左侧），关闭非当前页签保持当前路由不动；支持单行横向滚动、单页签 `×`/鼠标中键关闭、单页签右键菜单与最右侧纯图标下拉按钮（去除可见「页签操作」文字，保留可访问名称与提示；菜单提供固定/取消固定与分隔线下的「关闭其他页签」「关闭右侧页签」）；不提供页签内强制刷新按钮。
  - 所有涉及离开当前页面的切页、关闭当前页签或批量关闭均走标准路由导航并遵守现有 `UnsavedGuard` 未保存修改拦截，用户取消离开时保留原页签与当前编辑态。
- **侧边栏与静态层级面包屑升级**：
  - 侧边栏首次挂载时默认展开全部可见分组（用户仍可手动折叠并在挂载周期内保持选择，不被路由切换改写）。
  - 桌面端（`>850px`）顶栏左上角新增侧边栏完整收起/展开切换按钮（收起后让出 `228px` 横向空间给宽表格，不提供纯图标折叠栏，收起状态仅内存保留）。
  - 移除侧边栏底部与右上角账号菜单重复的用户名区块。
  - 顶栏面包屑由固定两级升级为按路由静态生成的完整层级（详情与编辑页携带 `#ID`，如 `工作台 / 角色管理 / 角色详情 #3 / 编辑权限`），中间层级可点击返回并遵守未保存修改保护。
- **工作台页头排版与桌面端信息密度调优**：
  - 工作台主界面标题改用无衬线 `Noto Sans SC`，`h1` 收敛至 `22–24px` 粗体，去除或弱化纯装饰性英文 eyebrow 前缀，收紧内容区顶部边距至 `20–24px`；保留面向读屏器的路由切换程序聚焦，同时消除 `h1[tabIndex=-1]` / `main[tabIndex=-1]` 程序聚焦产生的刺眼外框（键盘交互控件 `:focus-visible` 外框不变）。
  - 桌面端（`>850px`）常规按钮/输入框/筛选器收敛至 `36px`，表内操作与分页控件 `32–34px`，侧边栏导航项 `36–38px`；取消桌面端表格 `88px`/`100px` 强制行高，改为紧凑自然行高（表头 `40px`，单元格 `padding: 10px 16px`），数字列启用等宽数字 `tabular-nums`，卡片内边距与间距适度收敛；全站状态徽章统一防折行（`white-space: nowrap; flex-shrink: 0`）。
  - 移动端（`≤850px`）保留 `44px` 触控目标与既有响应式卡片布局，确保 `375px`、`850px`、`1440px` 视口无页面级横向滚动。
- **非目标**：
  - 不实现页面组件内存 Keep-Alive 保活或表单草稿跨页签缓存；不按单个对象 ID 独立拆分多个详情/编辑页签；不将页签、固定状态、侧边栏收起状态或分组展开状态写入 Web Storage 或同步到服务端。
  - 不更换冷白／深海青亮暗色主题体系或切换组件库；不修改登录/注册页品牌视觉样式；不把 `web/preview.html` 变成正式入口。
  - 不修改任何后端 HTTP 路由、数据模型、权限码、Redis key、MinIO bucket 或业务写入/查询契约，不新增第三方 npm 依赖。

## Capabilities

### New Capabilities

无。已打开页面栏、层级面包屑、侧边栏展开/收起及桌面端可读性密度均属于现有管理工作台壳层与界面基线的演进，不另立重复能力域。

### Modified Capabilities

- `admin-workbench`：更新“正式工作台使用真实服务与已审核的界面基线”与“工作台导航分组与响应式壳层”的需求与场景，纳入桌面端已打开页面栏、静态层级面包屑、默认展开全部可见分组、桌面端侧边栏完整收起、移除侧栏底部重复账号区块、无衬线紧凑页头与桌面端信息密度基线，同时保持认证、会话、Web Storage 限制、权限过滤与 `UnsavedGuard` 契约不变。

## Impact

- **前端模块**：
  - 导航与页签：`web/src/lib/workbench-navigation.ts`，新增 `web/src/lib/workbench-tabs.ts` 与 `web/src/components/WorkbenchTabBar.tsx`。
  - 壳层与通用组件：`web/src/components/ui/sidebar.tsx`、`web/src/components/WorkbenchShell.tsx`、`web/src/components/management/shared.tsx`。
  - 样式与页面页头：`web/src/styles.css`、`web/src/management.css`，以及管理页/个人资料页的 eyebrow 与数字列对齐微调（`RolePages.tsx`、`UserPages.tsx`、`OrganizationPages.tsx`、`ConfigurationPages.tsx`、`AuditLogPages.tsx`、`AuthorizationOverviewPages.tsx`、`ProfilePage.tsx`）。
  - 测试：`web/src/lib/workbench-navigation.test.tsx`、`web/src/components/ui/sidebar.test.tsx`、`web/src/components/WorkbenchShell.test.tsx`，以及新增页签状态与交互单元测试。
- **依赖与存储**：复用现有 React、React Router、Radix UI（含 `@radix-ui/react-dropdown-menu`、`@radix-ui/react-collapsible`、`@radix-ui/react-dialog`）与 Lucide 图标，不新增第三方依赖；不新增任何 Web Storage 键，不改变 Cookie 或会话恢复行为。
- **后端路由 / 模型 / 权限码 / Redis / MinIO**：无任何新增或变更；前端 React Router 路径表与权限判断逻辑保持与现行主规格一致。
- **兼容性**：无破坏性 API 变更；现有仅针对旧“默认只展开当前分组”和“固定两级面包屑”的前端断言与单测将在本次变更中同步更新为新契约。
