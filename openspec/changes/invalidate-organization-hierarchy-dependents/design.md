## Context

Scope当前org_and_children取用户成员组织及后代；all角色会提前返回，因而不能直接比较最终ResolveOrganizationScope结果来计算本次依赖。I4明确按层级事实依赖，包括旧/新祖先根的树外用户，而非移动节点成员或最终权限差分。

依据[proposal](proposal.md)及其引用审计/裁决；本文件描述未来实施，不代表已改代码或执行验收。实际路径遵ADR0006的internal业务模块、caller-owned Contract与App唯一组合根，不沿用已登记为旧提示的顶层技术目录。

## Goals / Non-Goals

**Goals:**

- 对真正parent_id变化读取锁定的旧新父关系，按org_and_children等当前层级依赖识别范围根变化及其用户。
- 包含旧/新祖先范围根的树外用户；另一角色重复/全量授权不豁免已有层级事实依赖。
- 组织移动与去重后的受影响用户版本同一最外层事务，失败全回滚；仅成员变化仍走独立I1规则。
- 不以最终合并权限差异或移动节点当前成员替代依赖计算；无结构变化不触发本目标。

**Non-Goals:**

不实现I3复杂菜单权限图精度、不枚举逐用户最终有效权限，不引入全局依赖缓存或分布式事件，不把纯组织展示字段变化当成结构移动。

## Decisions

### 1. 沿旧新父链定位改变的范围根

在C4锁定父图中确定移动节点的旧/新祖先根；仅当parent_id真正变化时分析哪些根的后代组织集合发生改变。复用一次父图及祖先路径，不复制两份全用户有效权限结果。

**理由与替代方案**：普通org/self/custom的固定组织ID不因本次父边移动自动变化；对org_and_children相关根计算真实层级事实依赖。

### 2. Authorization提供最小依赖用户能力

Organization定义消费Contract，由App桥接到Authorization：以改变的范围根查询具有适用org_and_children角色、且成员组织命中这些根的用户。角色/成员/范围配置遵生命周期同步协议稳定读取；不因另一个all角色早退而遗漏依赖。

**理由与替代方案**：仅返回去重用户ID与错误，不暴露角色ORM或让Organization扫所有用户再逐个Snapshot；不新增全局依赖缓存/事件总线。

### 3. 移动与版本同事务

锁定旧图、计算根变化与依赖、写父级及有序批量处理版本共同在一个最外层Context事务；组织引用/成员/范围写入与相同层级协议一致。失败全回滚，重试每attempt重算。

**理由与替代方案**：覆盖删除/成员变更造成依赖集合变化的真实交错，不用提交后异步补版本；无结构变化不触发该能力。

### 实施与规格发布依赖

- 功能/写入协议前置：`fix-concurrent-organization-moves`、`enforce-authorization-reference-lifecycle`
- 共享Requirement发布基线：`enforce-authorization-reference-lifecycle`
- 本delta对重复Requirement使用包含前置增量的完整正文，不能乱序归档覆盖。功能依赖与发布依赖不是同一含义；无功能依赖的源码工作可独立，但发布须按此基线。每个前置必须先实施、验证并按流程同步到主规格；若主规格另有变化，合并保留其新增场景，不以旧全文覆盖。

## Risks / Trade-offs

- 只枚举移动节点成员会漏树外读者 → 构造旧祖先/新祖先成员根用户及all+org_and_children重复角色案例。
- 直接用最终Scope导致all早退/多角色抵消 → 查询逐角色事实依赖，而非合并最终权限结果。
- 跨模块读与版本未加入同一事务 → 使用App显式桥接及真实第二用户版本失败全投影回滚。

## Verification

- 移动子树改变旧/新祖先org_and_children边界，树外根成员用户也失效；不相关用户不因本目标下线。
- 同用户另有all或重复角色仍按该事实依赖失效；无实际parent变动、只有组织展示字段或纯成员变化不触发本目标。
- 在版本第二项失败时父图和全部版本回滚；成功后使用事前未过期Access/Refresh确认失效。
- 与成员/范围/删除的受控真实交错不能漏提交时依赖用户，C4无环门禁继续成立。

只为真实消费者行为/边界保留适用回归；HTTP权限、跨模块事务和并发需要真实存储/原程序场景，Fake或SQLite仅保留自身局部效力。当前只创建工件，未执行这些检查。

## Migration Plan

无DDL或全量回填。先完成C4和引用生命周期共同协议，停组织结构及相关范围/成员写流量并切换全部写实例，禁止绕过新协议混跑。现有授权版本不降值；回滚同样停写全量切换，不撤销已失效Token。

实施前确认上述依赖及既有DDL/装配，不打印凭据。此变更不新增HTTP路径、Redis key、MinIO bucket或权限码；涉及的现有入口和表见proposal。实施后更新对应审计状态与去敏证据，不能把剩余C6风险一并标完成。
