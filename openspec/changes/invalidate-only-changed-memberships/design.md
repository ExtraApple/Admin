## Context

Role.AssignUsersToRole与Organization.SetUsers用旧新成员并集；逐人角色/组织在Ensure并检查CAS后直接替换和提升。Organization.Repository已保留未移除joined_at，版本差分与时间保留是不同事实。

依据[proposal](proposal.md)及其引用审计/裁决；本文件描述未来实施，不代表已改代码或执行验收。实际路径遵ADR0006的internal业务模块、caller-owned Contract与App唯一组合根，不沿用已登记为旧提示的顶层技术目录。

## Goals / Non-Goals

**Goals:**

- 角色和组织整组成员按集合差分仅失效新增/移除用户，不重建保留成员或重置joined_at。
- 逐人角色/组织写入先检查当前expected_access_version，合法等价目标不提升，真实关系变化只提升目标用户。
- 逐人组织仅比较可管理关系，保留范围外关系和原时间；角色整组仍完整替换且越界删除拒绝。
- 两次合法no-op可成功；真实修改先提交后携旧版本的no-op仍冲突，两个真实修改最多一个提交。
- 保持受控软删旧关系清理、保护及失败原子性，不以最终有效权限是否相同计算关系变化。

**Non-Goals:**

不计算共享授权配置或组织结构的影响集合，不因范围内人员数据变化额外失效旁观者，不改变完整替换/可管理部分替换差异。

## Decisions

### 1. 集合差分同时控制写入与失效

原始目标和旧关系都完成管理/生命周期前提后，分别计算新增和移除，只有对称差用户进入版本处理。完整替换保持完整语义，Repository只删移除/插新增；保留成员不重建。

**理由与替代方案**：不以另一角色重复授权或最终权限差异代替归属事实；纯成员变化不失效其他数据读取者。

### 2. 逐人先CAS再no-op

保持共享独立版本行锁及现有Ensure初始规则；先比较expected_access_version并验证身份/范围/引用，再读取适用当前集合。无变化返回current，不调用EnsureAndIncrement；真实修改只调用一次。

**理由与替代方案**：两个合法no-op保持版本可成功；真实修改先提交后旧版本no-op仍409。初始缺行仅沿既有管理写入Ensure规则，拒绝时创建行随事务回滚，非登录认证不借机Ensure。

### 3. 可管理部分与隐藏事实分开

逐人组织只比较并差量维护可管理集合，隐藏关系原样保留；整组角色/组织仍是全替换，隐藏或受保护旧对象不能静默过滤。

**理由与替代方案**：joined_at不因重复绑定重置；软删旧清理由生命周期安全查询，不因为当前普通目录不可见省略保护。

### 4. 复用既有最外层事务

读取、差分、关系写入及全部实际变更用户版本在同一Context事务；用户ID去重排序，内部重试每attempt重算局部集合和返回版本。

**理由与替代方案**：不增新乐观版本字段或重试策略；已知tag测试构造参数债务只在需用该入口时更新调用，不重新运行来确认已知失败。

- 共享Requirement发布基线：`enforce-authorization-reference-lifecycle`、`enforce-protected-authorization-assignments`
- 本delta对重复Requirement使用包含前置增量的完整正文，不能乱序归档覆盖。功能依赖与发布依赖不是同一含义；无功能依赖的源码工作可独立，但发布须按此基线。每个前置必须先实施、验证并按流程同步到主规格；若主规格另有变化，合并保留其新增场景，不以旧全文覆盖。

## Risks / Trade-offs

- 比较全集误删隐藏关系或重置时间 → 分别验证完整/可管理接口的关系投影与joined_at，不能只看返回版本。
- CAS后读旧快照或版本先增后发现无变化 → 锁后current事实比较，no-op分支在版本提升前且在所有校验后。

## Verification

- 角色/组织整组A/B到B/C只提升A/C，B关系和时间/版本不变；其他范围内读取者不额外失效。
- 逐人重复合法集合、去重/排序等价与空可管理集合保持当前版本；隐藏关系及joined_at保持。
- 真实MySQL两次no-op、no-op先真实修改后、真实修改先旧版本no-op、两个真实修改、角色与组织维度交错均验证具体暂停点和返回码。
- 第二实际受影响用户版本失败则事实和先前版本全回滚；软删清理与保护/越权旧关系拒绝均保留。

只为真实消费者行为/边界保留适用回归；HTTP权限、跨模块事务和并发需要真实存储/原程序场景，Fake或SQLite仅保留自身局部效力。当前只创建工件，未执行这些检查。
